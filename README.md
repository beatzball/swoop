# launtz

An open-source launcher in the shape of Raycast, built the Unix way: fzf does
the finding, libghostty does the drawing, and every extension is a program
that prints lines.

Early days. There is nothing to install yet.

The plan, every design decision, and the work in progress live in the
[issues](https://github.com/beatzball/launtz/issues). Start there.
